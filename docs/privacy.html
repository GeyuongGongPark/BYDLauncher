개인정보 처리방침

최종 업데이트: 2025년 8월 14일

BYD Launcher는 사용자의 개인정보를 소중히 여깁니다. 본 앱은 기능 제공을 위해 필요한 최소한의 권한만 요청하며, 수집한 정보를 외부에 전송하거나 제3자와 공유하지 않습니다.

1. 수집하는 정보 및 목적

정보 권한 수집 목적 외부 전송
위치 (도시 수준) ACCESS_COARSE_LOCATION
ACCESS_FINE_LOCATION		 날씨 정보 조회를 위한 위도·경도 확인 OpenWeatherMap API에 위도·경도만 전송 (도시명 수준)
캘린더 일정 READ_CALENDAR 오늘 일정 표시 (제목·시각) 전송 없음 — 기기 내부에서만 처리
설치된 앱 목록 — 앱 서랍 및 즐겨찾기 표시 전송 없음
즐겨찾기 설정 — 선택한 앱 패키지명을 기기에 저장 전송 없음

2. 제3자 서비스

날씨 정보 제공을 위해 OpenWeatherMap을 사용합니다. 날씨 조회 시 기기의 위도·경도가 OpenWeatherMap 서버로 전송됩니다. OpenWeatherMap의 개인정보처리방침은 아래에서 확인하세요.

  • OpenWeatherMap 개인정보처리방침

그 외 분석 SDK, 광고 SDK, 크래시 리포팅 서비스 등 어떤 제3자 서비스도 포함하지 않습니다.

3. 정보 보관 및 삭제

  • 위치 정보는 날씨 요청 시에만 사용되며, 앱 내부에 저장되지 않습니다.
  • 즐겨찾기 앱 목록(패키지명)은 기기 내 DataStore에 저장되며 앱 삭제 시 함께 삭제됩니다.
  • 캘린더 데이터는 표시 목적으로만 읽으며 별도로 저장하지 않습니다.

4. 권한 거부 시 동작

  • 위치 권한 거부 — 날씨 카드에 "위치 권한 필요" 메시지가 표시됩니다. 나머지 기능은 정상 동작합니다.
  • 캘린더 권한 거부 — 캘린더 카드에 일정이 표시되지 않습니다. 나머지 기능은 정상 동작합니다.

5. 미성년자 보호

BYD Launcher는 차량 인포테인먼트 전용 앱으로, 만 14세 미만 아동을 대상으로 하지 않습니다. 아동의 개인정보를 의도적으로 수집하지 않습니다.

6. 방침 변경

본 방침이 변경될 경우 GitHub 저장소의 이 페이지를 통해 공지합니다. 변경 후 앱을 계속 사용하면 변경된 방침에 동의한 것으로 간주합니다.

7. 문의

개인정보 처리와 관련한 문의는 GitHub Issues를 통해 남겨주세요.
