AC Quick Control + Window Status

Toggle the air conditioner on/off and adjust the target temperature in ±1 °C steps directly from the SidePanel — no separate app needed. Calls the BYD DiLink SDK (BYDAutoAcDevice) via Reflection. Real-time window opening percentage for all four windows is also shown. Falls back to "unsupported" state gracefully when the SDK is unavailable.

Eco Drive Coach

A driving session starts automatically when you shift into Drive (D gear) and ends when you park (P gear). Harsh acceleration (pedal ≥ 80%) and harsh braking (≥ 70%) deduct points from your eco score; regenerative braking earns points back. Instant flash feedback — orange for harsh acceleration, red for harsh braking — keeps you aware in real time. Session results pop up automatically when you park. All session history is saved to a local Room database.

Dark / Darker Theme

One tap on the brightness icon in the SidePanel switches between the standard Dark theme (#0A0C12) and the full-black Darker theme (#000000). Your preference is saved to DataStore and persists across restarts. Tab transitions use a direction-aware slide animation (220 ms) for a polished feel.

Installation
Up and running in four steps
1

Download the APK

Get app-release.apk from the latest release.

2

Allow Unknown Sources

On the infotainment system, go to Settings → Security → Unknown Sources and enable it.

3

Install the APK

Open the downloaded file in the file manager and follow the install prompts.

4

Set as Default Launcher

Press the Home button — a launcher picker will appear. Select BYD Launcher and tap Always. You can also use the in-app Set as Default Home button.
