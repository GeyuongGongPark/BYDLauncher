Features
필요한 건 모두, 불필요한 건 없이
🌤

위치 기반 날씨

GPS 없이도 네트워크 위치로 현재 온도·습도·날씨 아이콘 표시. Play Services 불필요.

📅

캘린더 위젯

기기 캘린더와 동기화. 오늘의 일정을 최대 5개, 색상과 시작 시각 표시.

★

즐겨찾기 앱

자주 쓰는 앱 최대 8개 고정. 길게 눌러 편집 모드 진입, 순서 변경 가능.

🔍

앱 서랍 검색

설치된 앱 전체를 이름으로 즉시 검색. 앱 추가/삭제 시 자동 갱신.

↻

회전 디스플레이 대응

Atto 3(12.8"), Seal(15.6")의 회전 화면을 자동 감지해 레이아웃 전환.

⚡

전체화면 몰입

시스템 상태바·네비게이션 바 자동 숨김. 화면을 최대한 활용.

Installation
설치 방법
1

APK 다운로드

최신 릴리즈에서 app-release.apk 파일을 다운로드합니다.

2

알 수 없는 출처 허용

인포테인먼트에서 설정 → 보안 → 알 수 없는 출처 허용을 켭니다.

3

APK 설치

파일 매니저에서 다운로드한 APK를 열어 설치합니다.

4

기본 런처 설정

홈 버튼을 누르면 런처 선택 팝업이 나타납니다. BYD Launcher를 선택하고 항상을 탭합니다.
