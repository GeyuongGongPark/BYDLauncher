Installation
설치 방법
1

APK 다운로드

최신 릴리즈에서 app-release.apk를 다운로드합니다.

2

알 수 없는 출처 허용

인포테인먼트에서 설정 → 보안 → 알 수 없는 출처를 허용합니다.

3

APK 설치

파일 매니저에서 다운로드한 APK 파일을 열어 설치합니다.

4

기본 런처 설정

홈 버튼을 누르면 런처 선택 팝업이 나타납니다. BYD Launcher를 선택하고 항상을 탭합니다.
